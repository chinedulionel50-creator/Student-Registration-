# Student Registration System

A desktop application for registering and managing students, built with Python and CustomTkinter. Data is stored in a local SQLite database.

## Features

- Login screen with account creation, logout and change password
- Register students with name, email, matric number, course, phone, level, gender and birth date
- Input validation so bad or empty data is rejected
- Student table with search
- Edit student records
- Export student records to CSV
- Dark mode toggle
- Attendance and grades tracking
- SQLite database (`students.db`) for storage

## Requirements

- Python 3.8 or higher
- customtkinter

## Installation

1. Download or clone this repository.
2. Install the required library:

```
pip install customtkinter
```

## How to Run

```
python frames.py
```

The database file `students.db` is created automatically the first time you run the app.
