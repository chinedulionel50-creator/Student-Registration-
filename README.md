# News App

A simple desktop news reader built with Python and CustomTkinter. It fetches the latest headlines from RSS feeds and shows them in a clean, easy-to-use window.

## Features

- Fetches live headlines from RSS feeds
- Clean graphical interface built with CustomTkinter
- Simple and fast to run

## Requirements

- Python 3.8 or higher
- customtkinter
- feedparser

## Installation

1. Download or clone this repository.
2. Install the required libraries:

```
pip install customtkinter feedparser
```

## How to Run

```
python news_app.py
```

## Tech Stack

- Python
- CustomTkinter
- RSS (feedparser)
